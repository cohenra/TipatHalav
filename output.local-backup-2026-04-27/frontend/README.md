# TipatHalav — מחשבון גיל לטיפת חלב

אפליקציית React לחישוב גיל מדויק (חודשים/שבועות/ימים) ומועדי חיסונים משוערים. מותאמת RTL, פונט Rubik.

🌐 Live: https://cohenra.github.io/TipatHalav/

## פיתוח מקומי

```bash
npm install
npm run dev
```

## בילד לprod

```bash
npm run build
npm run preview
```

## דיפלוי

אוטומטי דרך GitHub Actions בכל push ל-`main`. הסטטיק עולה ל-GitHub Pages.

## Stack

- Vite 5 + React 18
- Tailwind CSS 3
- lucide-react (אייקונים)
- Rubik (Google Fonts)
